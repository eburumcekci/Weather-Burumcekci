# Ortak Hava Pro

Next.js tabanlı, beş hava modelini birleştiren PWA.

## Özellikler
- 30 kayıtlı konuma kadar cihazda kalıcı saklama
- Ana ekranda tüm konumlar
- ECMWF, GFS, ICON, UKMO ve Météo-France ortalaması
- Rüzgâr hızı–hamle hızı birlikte
- 48 saat ve 7 gün ayrıntı
- Deniz suyu sıcaklığı ve dalga yüksekliği
- iPhone/iPad ana ekran kurulumu

## Vercel
GitHub repository'sini Vercel'e import edin. Framework Preset otomatik olarak Next.js seçilmelidir.
